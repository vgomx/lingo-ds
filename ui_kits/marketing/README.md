# UI kit — Lingo Toolbox marketing site (light)

Light-theme landing page, built on the same components as the app via `[data-theme="light"]` on `<html>`.

## Files

| File | Section |
| --- | --- |
| `index.html` | Page assembly, sign-up dialog, toast |
| `MarketingNav.jsx` | Sticky blurred nav with wordmark and pill CTAs |
| `MarketingHero.jsx` | Hero copy, proof stats, and a **live** flashcard demo on a violet block (dark island via `data-theme="dark"`) |
| `MarketingTools.jsx` | Five-tool grid plus two alternating feature bands |
| `MarketingOpenSource.jsx` | Three ways to use the project (hosted / self-host / contribute) and the closing violet CTA panel |
| `MarketingFooter.jsx` | Link columns, newsletter field, language list, legal row |

## Notes

- The hero "screenshot" is the real `Flashcard` + `ReviewRating` components, not an image — no photography or illustration was supplied and none was invented.
- Prices and stats are plausible placeholders; replace before any real use.
